Build a complete, production-ready, **Mobile-First Next.js (Latest Version, App Router) web application using strictly JavaScript only (NO TypeScript, NO `.ts`/`.tsx` files)** for a village microfinance & weekly collections business ("గ్రామాల వసూళ్ల వివరాలు / Village Collections").

### 1. TECH STACK & DESIGN SYSTEM
- **Framework:** Latest Next.js (App Router, `.js`/`.jsx` only), Tailwind CSS, `lucide-react` for clean, moderate, classic icons, and `googleapis` for two-way live sync with Google Sheets & Google Drive.
- **Design & UX:**
  - **Mobile-First Classic Design:** Clean, uncluttered, high-contrast, card-based UI optimized for one-handed mobile field operations. Soft emerald/teal (`#0F766E` / `#10B981`) primary accents on clean white/slate surfaces (`#F8FAFC`), crisp borders, and readable typography.
  - **Bilingual UI (Telugu + English):** Every navigation item, button, card label, and table header must show clear **Telugu + English** labels (e.g., `ఎదుర్లంక (Edurlanka)`, `కొత్తపల్లి (Kothapalli)`, `వసూలు నమోదు (Record Collection)`, `కొత్త ఖాతా (Add Customer)`, `బ్యాగ్ నిల్వ (Bag Balance)`).
  - **Bottom Navigation Bar (Mobile) / Top Header (Desktop):**
    1. `డాష్‌బోర్డ్ (Dashboard)`
    2. `ఎదుర్లంక (Edurlanka)`
    3. `కొత్తపల్లి (Kothapalli)`
    4. `ఖాతా లెక్కలు (Ledger)`
    5. `పెట్టుబడులు (Investments)`

### 2. GOOGLE SHEETS & DRIVE TWO-WAY SYNC ARCHITECTURE
Connect using `.env.local` variables (`GOOGLE_SPREADSHEET_ID`, `GOOGLE_DRIVE_FOLDER_ID`, `GOOGLE_SERVICE_ACCOUNT_EMAIL`, `GOOGLE_PRIVATE_KEY` — handle `\n` replacement in private key).
- **Live Read & Write:** Any edit, new customer addition, collection entry, ledger transaction, or photo/GPS upload in the Next.js app must immediately write to Google Sheets. Any direct edit in Google Sheets must reflect when refreshing or polling data in the app.
- **CRITICAL FORMULA PROTECTION:** Never overwrite the bottom `"మొత్తం (Total)"` summary rows in the village tabs! When adding a new customer, dynamically find the last customer row (above the Total row) and insert a new row (`insertDimension` + `values.update`) so existing `=SUM(...)` formulas auto-expand safely.

### 3. EXACT GOOGLE SHEET TABS & COLUMN SCHEMAS

#### Tab 1 & Tab 2: `'ఎదుర్లంక (Edurlanka)'` and `'కొత్తపల్లి (Kothapalli)'`
Exact columns (Columns A to R):
- **Col A:** `తేదీ (Date)` (DD-MM-YY format)
- **Col B:** `వ.సం. (S.No.)`
- **Col C:** `ఆసామీ పేరు (Telugu Name)`
- **Col D:** `English Transliteration`
- **Col E:** `సొమ్ము (Amount)` (Face Value)
- **Col F:** `ఫోన్ నంబర్ (Phone)` (10-digit clickable `tel:` link in UI)
- **Col G:** `కాలనీ (Colony)` (e.g., `జగన్`, `MD` in Edurlanka)
- **Col H:** `పేమెంట్ విధానం (Payment Type)` (Blank for Weekly 25-week scheme, or `నెల (Monthly)`)
- **Col I to N (Dynamic Weekly Columns):** `1 (10/10/26)`, `2 (17/10/26)`, `3 (24/10/26)`, `4 (31/10/26)`, `5 (7/11/26)`, `6 (14/11/26)` — *Also support adding a new Week Column (e.g., `7 (21/11/26)`) before the Remarks column from the UI!*
  - Cell values can be numeric (`500`, `1000`) for Cash, or tagged (`1000 (UPI)`, `500 (UPI)`) for PhonePe/UPI.
- **Col O:** `ఇతర వివరాలు / Remarks` (Stores `ష్యూరిటీ: XX (Surety: XX)`, `ఫోన్ చేయాలి (Phone Reminder - P)`, `Struck out`, `హోటల్ (Hotel)`, etc.)
- **Col P:** `GPS లొకేషన్ (GPS Location)` (Google Maps URL)
- **Col Q:** `కార్డ్ ఫోటో (Card Photo)` (Google Drive image link)
- **Col R:** `ఇంటి ఫోటో (House Photo)` (Google Drive image link)

#### Tab 3: `'పెట్టుబడులు (Investments)'`
- **Partner Summary Table (Rows 1–3):** `భాగస్వామి సారాంశం (Partner Summary)`, `మొత్తం పెట్టుబడి (Total Investment)`, `వాటా శాతం (Share %)` (`పృధ్వి (Prudhvi)` & `సత్తిబాబు (Sattibabu)`).
- **Temporary Safety Deposit Memo Table (Rows 5–6):** `తేదీ (Date)`, `వివరాలు (Particulars)`, `ఇన్ / క్రెడిట్ (Inflow)`, `అవుట్ / డెబిట్ (Outflow)`, `నికర నిల్వ (Net Status)`.
- **Permanent Investment Log (Row 8+):** `తేదీ (Date)`, `భాగస్వామి పేరు (Partner Name)`, `పెట్టుబడి మొత్తం (Investment Amount)`.

#### Tab 4: `'ఖాతా లెక్కలు (Ledger Reconciliation)'`
- **Account Summary (Rows 1–5):** `మొత్తం పెట్టుబడి (Total Capital Added)`, `తాత్కాలిక సేఫ్టీ డిపాజిట్ (Safety Fund Inflow)`, `మొత్తం వసూళ్లు (Total Collections)`, `మొత్తం ఖర్చులు & వాపసులు (Total Expenses & Returns)`.
- **Ledger Transactions (Row 7+):** `తేదీ (Date)`, `వివరాలు (Particulars)`, `క్రెడిట్ / ఇన్ (Credit/In)`, `డెబిట్ / అవుట్ (Debit/Out)`, `నిల్వ (Balance)`.

#### Tab 5: `'లాభ-నష్టాలు (P&L Analytics)'`
- Reads KPIs (`బ్యాగ్ నిల్వ`, `మార్కెట్ బాకీలు`, `మొత్తం వ్యాపార ఆస్తులు`, `మొత్తం అంచనా లాభం`), Loan Scheme Unit Economics table, Village-wise Recovery table, Combined Weekly Collections table, and Partner Equity & Profit Distribution table.

### 4. CORE BUSINESS LOGIC & LOAN SCHEMES
1. **Loan Scheme Lookup (Face Value $\rightarrow$ Disbursed Principal $\rightarrow$ Installment):**
   - `₹25,000` $\rightarrow$ Disbursed `₹19,800` | Weekly `₹1,000` (25 weeks)
   - `₹18,750` $\rightarrow$ Disbursed `₹14,850` | Weekly `₹750` (25 weeks)
   - `₹14,000` (Monthly 12-Mo) $\rightarrow$ Disbursed `₹9,900` | Monthly `₹1,167`
   - `₹12,500` $\rightarrow$ Disbursed `₹9,900` | Weekly `₹500` (25 weeks)
   - `₹6,300` $\rightarrow$ Disbursed `₹5,000` | Weekly `₹250` (25 weeks)
   - `₹5,000` $\rightarrow$ Disbursed `₹4,000` | Weekly `₹200` (25 weeks)
   - `₹2,500` $\rightarrow$ Disbursed `₹2,000` | Weekly `₹100` (25 weeks)
   - `₹1,250` $\rightarrow$ Disbursed `₹1,000` | Weekly `₹50` (25 weeks)
2. **Struck-Out Accounts:** Any row with `"Struck out"` in Remarks (e.g., Edurlanka S.No 6) must be visually shown with a strikethrough badge and **excluded** from active portfolio receivables, active dues, and expected profit calculations.
3. **Smart Badges & Field Indicators:**
   - **Phone Reminder (`ఫోన్ చేయాలి`):** Highlight customers with `"ఫోన్ చేయాలి"` in Remarks with a prominent amber bell/phone badge so field agents remember to call them for PhonePe payment.
   - **Monthly (`నెల`) vs Weekly:** Badge monthly accounts clearly and calculate remaining balance (`Face Value - Sum of Paid Installments`).
   - **Surety (`ష్యూరిటీ`):** Make surety numbers clickable/searchable to see who guaranteed the borrower.
   - **Colony Filter (`జగన్`, `MD`, All):** Quick filter pills on Edurlanka tab.

### 5. KEY APP FEATURES TO BUILD
1. **Dashboard (`డాష్‌బోర్డ్`):**
   - Top KPI Cards: `బ్యాగ్ నిల్వ (Bag Cash Balance)`, `మార్కెట్ బాకీలు (Active Dues)`, `మొత్తం వసూళ్లు (Total Collected)`, `అంచనా లాభం (Expected Profit)`.
   - Village Recovery Progress bars (`ఎదుర్లంక` vs `కొత్తపల్లి`).
   - Weekly Collections Trend list & Partner Profit Split (`సత్తిబాబు` vs `పృధ్వి`).
2. **Village Customer List & Quick Collection Entry (`ఎదుర్లంక` & `కొత్తపల్లి`):**
   - Instant search by Name, S.No, Phone, or Surety, plus filters (`All`, `Weekly`, `Monthly`, `Phone Reminder`, `జగన్`, `MD`).
   - Each customer card shows: S.No, Telugu + English Name, Loan Face Value, Paid so far, Remaining Due, Phone Call button (`tel:`), GPS Map link button (if available), and Photo buttons.
   - **One-Tap Collection Modal:** Tap a customer $\rightarrow$ select Week (or create a new Week column) $\rightarrow$ enter Amount (auto-filled with standard installment) $\rightarrow$ toggle `Cash (నగదు)` vs `PhonePe / UPI` $\rightarrow$ Save directly to Google Sheet!
   - **Edit Customer / Upload GPS & Photos Modal:**
     - Button to capture current mobile GPS (`navigator.geolocation`) and save the `https://maps.google.com/?q=lat,lng` link directly into the `GPS లొకేషన్` column.
     - File input (`accept="image/*" capture="environment"`) to upload **Card Photo** or **House Photo** $\rightarrow$ API route uploads image to Google Drive folder (`GOOGLE_DRIVE_FOLDER_ID`), sets public/anyone-with-link view permission, and writes the Google Drive link into `కార్డ్ ఫోటో` or `ఇంటి ఫోటో` column in the sheet.
3. **Add New Customer Form (`కొత్త ఖాతా చేర్చండి`):**
   - Select Village (`ఎదుర్లంక` / `కొత్తపల్లి`), Date, S.No (auto-suggested next number), Telugu Name, English Name, Scheme Amount (dropdown with auto-disbursed preview), Phone, Colony (`జగన్` / `MD` / Other), Payment Type (`Weekly` / `నెల Monthly`), Surety S.No, and Remarks $\rightarrow$ inserts row cleanly above the Total row in Google Sheets.
4. **Ledger & Investments (`ఖాతా లెక్కలు` & `పెట్టుబడులు`):**
   - View chronological cash inflows/outflows with running bag balance, and add new `పెట్టుబడి (Capital)`, `ఖర్చు (Expense)`, or `వసూలు (Collection)` entries that auto-calculate the new running balance in the sheet.
