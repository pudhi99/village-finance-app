# గ్రామాల వసూళ్ల వివరాలు (Village Collections App)

A modern, fast, mobile-first microfinance & weekly loan collections web application built with **Next.js (App Router, JavaScript/React)**, **Tailwind CSS**, and **Google Sheets & Google Drive two-way live sync**.

---

## 🚀 ఫీచర్లు (Key Features)

### 1. మొబైల్ ఫస్ట్ క్లాసిక్ డిజైన్ (Mobile-First UI)
- ఫీల్డ్ కలెక్షన్స్ ఏజెంట్స్ కోసం ఒకే చేత్తో ఆపరేట్ చేయగల ఆధునిక, క్లీన్ కార్డ్ బేస్డ్ ఇంటర్‌ఫేస్.
- **ద్విభాషా ఇంటర్‌ఫేస్ (Bilingual UI):** తెలుగు మరియు ఇంగ్లీష్ లేబుల్స్ (`ఎదుర్లంక (Edurlanka)`, `కొత్తపల్లి (Kothapalli)`, `వసూలు నమోదు`, `బ్యాగ్ నిల్వ`, మొదలైనవి).
- మొబైల్ బాటమ్ నావిగేషన్ బార్ & డెస్క్‌టాప్ హెడర్.

### 2. లైవ్ గూగుల్ షీట్స్ & డ్రైవ్ సింక్ (Two-Way Google Sheets & Drive Sync)
- **ఫార్ములా ప్రొటెక్షన్:** షీట్‌లో కింద ఉండే `"మొత్తం (Total)"` రో ని ఎప్పుడూ ఓవర్‌రైట్ చేయదు. కొత్త కస్టమర్‌ను చేర్చేటప్పుడు `insertDimension` ద్వారా రో ని చొప్పించి `=SUM(...)` ఫార్ములాలు ఆటోమేటిక్‌గా విస్తరించేలా చేస్తుంది.
- **వన్-ట్యాప్ వసూలు నమోదు (One-Tap Collection):** కస్టమర్‌పై ట్యాప్ చేసి వారం, మొత్తం, మరియు నగదు (Cash) లేదా PhonePe / UPI సెలెక్ట్ చేసి నేరుగా గూగుల్ షీట్‌లోకి సేవ్ చేయవచ్చు.
- **మొబైల్ లైవ్ GPS:** బ్రౌజర్ జియోలొకేషన్ ద్వారా ప్రస్తుత GPS లొకేషన్‌ను ఒక క్లిక్‌తో గూగుల్ మ్యాప్స్ లింక్‌గా షీట్‌లో నమోదు చేయవచ్చు.
- **కార్డ్ & ఇంటి ఫోటోలు (Card & House Photos via Cloudinary):** మొబైల్ కెమెరా లేదా గ్యాలరీతో ఫోటో తీసి Cloudinary లోని ప్రత్యేక ఫోల్డర్లలో (`village-finance/Cards` మరియు `village-finance/houses`) ఆటోమేటిక్‌గా అప్‌లోడ్ చేసి వేగవంతమైన CDN లింక్‌ను గూగుల్ షీట్‌కు సేవ్ చేస్తుంది.
- **కొత్త వారం కాలమ్ (Add Week Column):** ఫీల్డ్ నుండే కొత్త శనివారం వారం కాలమ్‌ను (ఉదా: `7 (21/11/26)`) షీట్‌లోకి జోడించవచ్చు.

### 3. మైక్రోఫైనాన్స్ లోన్ స్కీమ్స్ (Unit Economics & Loan Schemes)
- **₹25,000** ➔ ఇచ్చేది ₹19,800 | వారం ₹1,000 (25 వారాలు)
- **₹18,750** ➔ ఇచ్చేది ₹14,850 | వారం ₹750 (25 వారాలు)
- **₹14,000 (నెల 12-Mo)** ➔ ఇచ్చేది ₹9,900 | నెల ₹1,167
- **₹12,500** ➔ ఇచ్చేది ₹9,900 | వారం ₹500 (25 వారాలు)
- **₹6,300** ➔ ఇచ్చేది ₹5,000 | వారం ₹250 (25 వారాలు)
- **₹5,000** ➔ ఇచ్చేది ₹4,000 | వారం ₹200 (25 వారాలు)
- **₹2,500** ➔ ఇచ్చేది ₹2,000 | వారం ₹100 (25 వారాలు)
- **₹1,250** ➔ ఇచ్చేది ₹1,000 | వారం ₹50 (25 వారాలు)

### 4. స్మార్ట్ ఇండికేటర్లు
- **ఫోన్ చేయాలి (Phone Reminder):** PhonePe చెల్లింపుల కోసం కాల్ చేయాల్సిన కస్టమర్లకు ప్రత్యేక అంబర్ బెల్ బ్యాడ్జ్.
- **Struck-Out Accounts:** రద్దు అయిన ఖాతాలను స్ట్రైక్-త్రూ తో చూపిస్తూ మార్కెట్ బాకీల నుండి వేరుగా ఉంచుతుంది.
- **కాలనీ ఫిల్టర్లు:** `జగన్`, `MD` కాలనీలను సులభంగా ఫిల్టర్ చేసుకోవచ్చు.
- **ష్యూరిటీ (Surety):** ఏ కస్టమర్‌కు ఎవరు ష్యూరిటీ ఉన్నారో క్లియర్ బ్యాడ్జ్ రూపంలో ప్రదర్శిస్తుంది.

## 🛠️ ప్రాజెక్ట్ రన్ చేసే విధానం (How to Run)

### డెవలప్‌మెంట్ సర్వర్ స్టార్ట్ చేయడానికి:
```bash
npm run dev
```
బ్రౌజర్‌లో [http://localhost:3000](http://localhost:3000) ఓపెన్ చేయండి.

### ప్రొడక్షన్ బిల్డ్ చేయడానికి:
```bash
npm run build
npm run start
```
